\section{Sectioning}
A good practice is to start with an introduction section, which describes the background and motivation behind the project, how the project is implemented, and the main results and key findings. Next, describe in detail each component of your system, e.g., datasets, model architecture, training, and evaluation. Finally, present the experiments and results, and conclude this project with key insights, limitations, and future outlook.

\paragraph{Author Contributions}
Please include an independent section named \textit{Author Contributions} after the conclusion section. In this section, you need to specify the contributions of each author as well as the weighting. Using a table may help.
